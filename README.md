# Customer Sales Data Cleaning

##  Project Overview

This project focuses on cleaning and preparing a **Customer Sales Data** dataset obtained from an online web platform. The main objective was to identify and resolve common data quality issues and make the dataset suitable for further analysis.

##  Tool Used

* **Microsoft Excel**

##  Data Quality Issues Identified

The dataset contained several data quality issues, including:

* Missing values
* Duplicate records
* Incorrect data types
* Inconsistent values
* Improper formatting of text and date fields

##  Data Cleaning Performed

The following cleaning activities were performed using Excel:

* Removed duplicate records.
* Identified and handled missing values.
* Corrected incorrect data types.
* Standardized text formatting and values.
* Properly formatted date fields.
* Reviewed the dataset for consistency and accuracy.
* Calculated the **total sales amount** using Excel.

##  Outcome

The cleaned dataset is more consistent, structured, and ready for further analysis and reporting.
